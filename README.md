## 🧮 没有内建数字（这是全新设计）

- **所有会决定「买／卖／跳过／排除／通知／标签」的东西，都是「开关＋你自己填的数字」**，预设全部关着、数字全部空白。
- 新安装：雷达只看盘，不会自动买、不会自动卖，直到你自己在「🎯 自订策略」把条件和数字填好、按「保存并启动」。
- **读不到资料 → 不买**；或照你自己选的「读不到时用备用条件」（备用条件的数字也是你填的）。没有偷偷的备用路径。
- 每一次买／不买都逐条写原因：「✅ 进度 72%（你设至少 X%）　❌ Agent 钱包 30 个（你设介于 A 到 B）→ 不买」（X、A、B 是你自己填的数字），在雷达日志和 `data/decisions.jsonl` 都看得到。
- 画面上的灰色字（例如「建议 50」）只是提示，**栏位还是空的，引擎不会读**。
- **工具不替你做决定，只给清楚的警告**：你手动下的单，工具觉得有风险时会写出原因，让你按「我知道风险，仍然执行」自己决定；自动的单只照你的设定。风险和关键字只当标签显示，不会偷偷跳过或藏起来。
- 只有纯运作用的常数留在程式里（轮询间隔、区块分页、重试间隔、快取时间），它们不会改变买什么、卖什么、通知什么。

## 🚀 安装（建议让你的 AI 帮你跑）

需要一台 24 小时开着的 **Windows 或 Mac 电脑**（Node.js 22.15 以上，没有或太旧的话安装程式会帮你装／更新；旧版 Node 外挂沙盒跑不起来）、不限流量的网络（引擎用公共节点下载区块，**大约每天 11～45 GB**，看你开了几条链）、币安 App 里已开通 Agentic Wallet（.ai Agent ID）并开启开发者模式、钱包里有一点 BNB 付手续费。

**Windows**：把下面这段丢给你电脑上能执行指令的 AI（或自己贴到 PowerShell）：

```powershell
winget install -e --id Git.Git --accept-source-agreements --accept-package-agreements
$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')
git clone https://github.com/nancyc0813-maker/robincat-radar.git "$HOME\Desktop\RobinCatRadar"
cd "$HOME\Desktop\RobinCatRadar"; .\一键安装.bat
```

**Mac**：打开「终端机」（Terminal），贴上：

```bash
git clone https://github.com/nancyc0813-maker/robincat-radar.git ~/Desktop/RobinCatRadar && bash ~/Desktop/RobinCatRadar/一键安装-Mac.command
```

（第一次用 git 时 Mac 会跳出「安装开发者工具」，按安装，装好后再贴一次。没有 Node.js 时有 Homebrew 会自动 `brew install node`，没有就提示你到 nodejs.org 下载安装。Mac 要设定成不自动睡眠，不然会漏单。）

装好后桌面会有「罗宾猫雷达」。第一次打开：准备币安 AI 钱包（已经有就跳过）→ 输入邀请码 → 用币安 App 扫码连接钱包 → 到「🎯 自订策略」自己填条件和数字 → 按「保存并启动」。没填之前雷达只看盘。

**有新版时**：雷达右上角会显示「有新版」（TG 提醒要你自己在设定打开「新版 TG 提醒」），要你自己在雷达按更新、或在 TG 回「更新」才会更新；更新档一定要验过官方签名才会换上。更新后如果引擎没启动成功，**不会自动退回旧版**：雷达会写出原因、给你「重新下载这一版」「查看日志」，并发 TG 通知你。
